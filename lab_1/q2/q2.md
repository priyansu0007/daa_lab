# Q2. Simulation of Fair and Biased Coin Probability Convergence

## Problem Statement

A coin toss is a random experiment where the outcome can either be **Heads** or **Tails**.

This program simulates:

1. A **fair coin**
   - Probability of getting Heads = 0.5

2. A **biased coin**
   - Probability of getting Heads is determined by the user-provided bias value.

The program performs a large number of tosses, calculates the cumulative probability of Heads after every toss, stores the data in a file, and plots the convergence of experimental probabilities using GNUplot.

---

# Objective

The objectives of this experiment are:

- Simulate random coin tosses using C.
- Compare fair and biased coin behavior.
- Observe how experimental probability approaches theoretical probability.
- Demonstrate the **Law of Large Numbers**.
- Analyze why probability values converge as the number of tosses increases.

---

# C Program

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main()
{
    FILE *file = fopen("coin.dat", "w");

    if (file == NULL)
    {
        printf("Error opening file!\n");
        return 1;
    }

    int tosses;
    double bias;

    printf("Enter number of tosses: ");
    scanf("%d", &tosses);

    printf("Enter bias (0 to 1): ");
    scanf("%lf", &bias);


    if (bias < 0 || bias > 1)
    {
        printf("Invalid bias!\n");
        return 1;
    }


    int fairHeads = 0, fairTails = 0;
    int biasedHeads = 0, biasedTails = 0;


    srand(time(NULL));


    for (int i = 1; i <= tosses; i++)
    {

        // Fair coin simulation
        if (rand() % 2 == 0)
            fairHeads++;
        else
            fairTails++;


        // Biased coin simulation
        double randomValue = (double)rand() / RAND_MAX;

        if (randomValue < bias)
            biasedHeads++;
        else
            biasedTails++;


        fprintf(file, "%d %.4f %.4f\n",
                i,
                (double)fairHeads / i,
                (double)biasedHeads / i);
    }


    fclose(file);


    printf("\n========== SIMULATION RESULT ==========\n");


    printf("\nFair Coin (P(Head) = 0.5)\n");
    printf("Heads = %d\n", fairHeads);
    printf("Tails = %d\n", fairTails);
    printf("Probability of Head = %.4f\n",
           (double)fairHeads / tosses);


    printf("\nBiased Coin (P(Head) = %.2f)\n", bias);
    printf("Heads = %d\n", biasedHeads);
    printf("Tails = %d\n", biasedTails);
    printf("Probability of Head = %.4f\n",
           (double)biasedHeads / tosses);


    printf("\nSimulation completed.\n");
    printf("Data saved in coin.dat\n");


    return 0;
}
```

# Theory

## Probability of a Coin Toss

For a fair coin:

\[
P(Head)=0.5
\]

\[
P(Tail)=0.5
\]

For a biased coin:

\[
P(Head)=b
\]

where `b` is the bias value entered by the user.

Example:

If:

```
bias = 0.7
```

then:

\[
P(Head)=0.7
\]

and

\[
P(Tail)=0.3
\]

---

# Law of Large Numbers

The Law of Large Numbers states that:

> As the number of independent trials increases, the experimental probability approaches the theoretical probability.

For coin tossing:

\[
\frac{\text{Number of Heads}}{\text{Total Tosses}}
\]

approaches the actual probability of Heads.

Example:

For a fair coin:

Small sample:

```
10 tosses:
8 heads

Probability = 0.8
```

Large sample:

```
1,000,000 tosses:
500,000 heads approximately

Probability ≈ 0.5
```

# Why the Values Converge

The convergence occurs because of the **Law of Large Numbers**.

Each coin toss is random, so early results can vary significantly.

Example:

First 5 tosses:

```
H H H T H
```

Probability:

```
4/5 = 0.8
```

This is far from the fair probability:

```
0.5
```

because the sample size is small.

---

As the number of tosses increases:

```
10 tosses
100 tosses
10000 tosses
1000000 tosses
```

individual random outcomes have less influence on the overall average.

The cumulative probability becomes more stable.

---

## Why Fair Coin Converges to 0.5

For a fair coin:

\[
P(Head)=0.5
\]

As the number of tosses becomes very large:

\[
\frac{Heads}{Total\ Tosses}\rightarrow0.5
\]

The fluctuations become smaller and the curve settles around 0.5.

---

## Why Biased Coin Converges to the Bias Value

For a biased coin:

Example:

```
bias = 0.8
```

The expected probability is:

\[
P(Head)=0.8
\]

Therefore:

\[
\frac{Heads}{Total\ Tosses}\rightarrow0.8
\]

The red curve stabilizes near the bias value.

---

## Why the Curves Do Not Become Exactly Constant

Even with many tosses, the graph may not become a perfectly horizontal line.

This happens because:

- Randomness never disappears completely.
- The simulation uses finite samples.
- The probability only approaches the theoretical value.

The difference becomes smaller as the number of tosses increases.
