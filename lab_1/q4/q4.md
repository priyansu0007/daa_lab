# Q4. Analysis of Towers of Hanoi Using Recursion

## Problem Statement

The **Tower of Hanoi** is a classic recursive problem in computer science.

It consists of **three rods** and **N disks** of different sizes. Initially, all disks are stacked on the first rod in decreasing order of size (largest at the bottom and smallest at the top).

The objective is to move all the disks from the **source rod** to the **destination rod** while following these rules:

1. Only one disk can be moved at a time.
2. Only the top disk of any rod can be moved.
3. A larger disk cannot be placed on top of a smaller disk.

The program simulates the Tower of Hanoi recursively, counts the total number of moves for different numbers of disks, stores the results in a data file, and plots the graph using **GNUplot**.

---

# C Program

```c
#include <stdio.h>

// Recursive function to simulate Towers of Hanoi and count moves
void hanoi(int n, char from_rod, char to_rod, char aux_rod, unsigned long long *moves) {
    if (n == 0) {
        return;
    }

    // Move n-1 disks from source to auxiliary
    hanoi(n - 1, from_rod, aux_rod, to_rod, moves);

    // Move the nth disk
    (*moves)++;

    // Move n-1 disks from auxiliary to destination
    hanoi(n - 1, aux_rod, to_rod, from_rod, moves);
}

int main() {
    FILE *fp = fopen("toh_data.dat", "w");

    if (fp == NULL) {
        printf("Error opening file!\n");
        return 1;
    }

    fprintf(fp, "# Discs(N) Total_Moves\n");

    int max_discs = 25;

    printf("Simulating Towers of Hanoi up to %d discs...\n", max_discs);

    for (int n = 1; n <= max_discs; n++) {

        unsigned long long moves = 0;

        hanoi(n, 'A', 'C', 'B', &moves);

        fprintf(fp, "%d %llu\n", n, moves);

        printf("N = %2d | Moves = %llu\n", n, moves);
    }

    fclose(fp);

    printf("Simulation complete. Data saved to 'toh_data.dat'\n");

    return 0;
}
```

# Theory

The Tower of Hanoi follows the recursive relation:

```
T(n) = 2T(n−1) + 1
```

where

- **T(n)** = number of moves required for **n disks**

The closed-form solution is

```
T(n) = 2ⁿ − 1
```

This means every time one more disk is added, the number of required moves almost doubles.

---

# Approach

Instead of directly calculating

```
2ⁿ − 1
```

the program **simulates the recursive algorithm** exactly as it would solve the Tower of Hanoi.

For each value of **N** from **1 to 25**

- Execute the recursive algorithm.
- Count every disk movement.
- Store the number of moves in a file.
- Plot the results using GNUplot.

This demonstrates both the correctness and growth of the recursive algorithm.

---

# Step-by-Step Explanation

## Recursive Function

```c
if (n == 0)
    return;
```

This is the **base case**.

If there are no disks, no move is required.

---

### Step 1

Move the top **n−1** disks from the source rod to the auxiliary rod.

```c
hanoi(n-1, source, auxiliary, destination);
```

---

### Step 2

Move the largest disk.

```c
(*moves)++;
```

Instead of printing every move, the program simply increases the move counter.

---

### Step 3

Move the remaining **n−1** disks onto the destination rod.

```c
hanoi(n-1, auxiliary, destination, source);
```

# Complexity Analysis

## Time Complexity

The recurrence relation is

```
T(n) = 2T(n−1) + 1
```

Therefore,

```
Time Complexity = O(2ⁿ)
```

The number of recursive calls doubles for every additional disk.

---

## Space Complexity

Only the recursive call stack is used.

Maximum recursion depth

```
n
```

Therefore,

```
Space Complexity = O(n)
```

---

# What Happens for Very Large Input Sizes?

The Tower of Hanoi grows **exponentially**.

| Disks | Total Moves |
|------:|------------:|
| 10 | 1,023 |
| 20 | 1,048,575 |
| 25 | 33,554,431 |
| 30 | 1,073,741,823 |
| 40 | 1,099,511,627,775 |
| 50 | 1,125,899,906,842,623 |

Notice that adding just **one extra disk nearly doubles the number of moves**.

For very large values of **N**:

- Execution time increases rapidly.
- Millions or even billions of recursive calls are required.
- The recursion stack also grows linearly.
- Eventually, execution becomes impractical.

For example,

```
N = 50
```

requires over

```
1.12 quadrillion moves
```

which would take many years to complete on a typical computer.

# Conclusion

- The Tower of Hanoi is a classic example of **recursion**.
- The recursive solution follows the relation

```
T(n) = 2T(n−1) + 1
```

whose solution is

```
T(n) = 2ⁿ − 1
```

- The program simulates the recursive algorithm, counts every move, and stores the results in a data file.
- GNUplot is then used to visualize how the number of moves increases with the number of disks.
