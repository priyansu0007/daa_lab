# Q6. Find Duplicate Elements in an Array Using a Hash Array

## Problem Statement

Given an array of integers, determine whether the array contains **duplicate elements** using a **hash array**.

If any element appears more than once, print that the array contains duplicates. Otherwise, print that all elements are unique.

**Assumption:** The array elements are non-negative integers within a known range (for example, 0–1000), making a hash array feasible.

### Example

**Input:**
```text
arr = {45, 12, 89, 34, 12, 7, 99}
```

**Output:**
```text
The array contains duplicates.
```

---

# C Program

```c
#include <stdio.h>
#include <stdbool.h>

#define MAX_VALUE 1000

// Function to check for duplicate elements using a hash array
bool hasDuplicates(int arr[], int n) {
    int hash[MAX_VALUE + 1] = {0};

    for (int i = 0; i < n; i++) {

        if (hash[arr[i]] == 1) {
            return true;    // Duplicate found
        }

        hash[arr[i]] = 1;
    }

    return false;           // No duplicates
}

int main() {
    int arr[] = {45, 12, 89, 34, 12, 7, 99};
    int n = sizeof(arr) / sizeof(arr[0]);

    if (hasDuplicates(arr, n))
        printf("The array contains duplicates.\n");
    else
        printf("All elements in the array are unique.\n");

    return 0;
}
```

---

# Approach

The program uses a **hash array** to record which elements have already been encountered.

Initially, every position in the hash array contains `0`, meaning no element has been seen.

For each element in the input array:

- If its corresponding hash value is already `1`, the element has appeared before, so a duplicate exists.
- Otherwise, mark that element as seen by setting its hash value to `1`.

This allows duplicate detection in a single traversal of the array.

---

# Step-by-Step Explanation

### Input Array

```text
45 12 89 34 12 7 99
```

Initially,

```text
hash[] = {0, 0, 0, ...}
```

### Processing

- Read **45**
  - hash[45] = 0
  - Set hash[45] = 1

- Read **12**
  - hash[12] = 0
  - Set hash[12] = 1

- Read **89**
  - hash[89] = 0
  - Set hash[89] = 1

- Read **34**
  - hash[34] = 0
  - Set hash[34] = 1

- Read **12**
  - hash[12] = 1
  - Duplicate found

The function immediately returns `true`.

# Dry Run

| Element | Hash Status Before | Action |
|---------:|:------------------:|--------|
| 45 | 0 | Mark as visited |
| 12 | 0 | Mark as visited |
| 89 | 0 | Mark as visited |
| 34 | 0 | Mark as visited |
| 12 | 1 | Duplicate found |

**Output**

```text
The array contains duplicates.
```

---

# Algorithm

1. Create a hash array initialized with zeros.
2. Traverse the input array.
3. For each element:
   - If it has already been marked in the hash array, return `true`.
   - Otherwise, mark it as visited.
4. If the traversal completes, return `false`.

---

# Complexity Analysis

## Time Complexity

The array is traversed only once.

```text
Time Complexity = O(n)
```

---

## Space Complexity

The program uses an additional hash array.

```text
Space Complexity = O(MAX_VALUE)
```

If the maximum possible value is fixed (such as 1000), this is considered **constant extra space** with respect to the input size.

---

# What Happens for Very Large Input Sizes?

### Large Number of Elements

Suppose the array contains:

- 100,000 elements
- 1,000,000 elements

The algorithm still processes each element only once.

Therefore, the running time grows linearly.

```text
O(n)
```

This makes it much faster than sorting-based approaches for very large arrays.

---

### Large Element Values

The limitation of a hash array is that it requires an array large enough to index every possible value.

For example:

```text
Values:
5
18
999999999
```

A hash array of size **1,000,000,000** would be impractical because it would consume a huge amount of memory.

In such cases, a **hash table (HashMap/HashSet)** should be used instead of a simple hash array.

---

### When Is a Hash Array Suitable?

A hash array is efficient when:

- Element values are non-negative.
- The maximum value is reasonably small.
- Memory is sufficient.

Examples:

```text
Marks: 0–100
Student IDs: 1–5000
Numbers: 0–1000
```

---

# Why the Hash Array Works

Each array value is treated as an index into another array.

Example:

```text
Input:
45 12 89 34 12
```

After processing,

```text
hash[45] = 1
hash[12] = 1
hash[89] = 1
hash[34] = 1
```

When `12` appears again,

```text
hash[12] == 1
```

Therefore, the program immediately knows that `12` is a duplicate.

# Conclusion

- The program uses a **hash array** to record previously seen elements.
